わたしのことAbout

毎日の「いつもの作業」を、 仕組みにおまかせ。

請求書づくり、領収書の入力、問い合わせへの返信、SNSの投稿。毎日くり返している事務作業は、その多くを自動化できます。

takibinekoは、Claude・ChatGPTなどのAIと小さなプログラムを組み合わせて、あなたの仕事に合わせた自動化をつくる個人の開発者です。個人事業・小さなお店・中小企業のお手伝いをしています。

「何が自動化できるのか分からない」という段階で大丈夫です。今のやり方を聞かせていただくところから、一緒に始めさせてください。

自動化できることAutomation

たとえば、こんな作業をおまかせにできます。

  • 領収書・レシートの入力1枚ずつ見ながら表に打ち込む

    写真やPDFを置くだけで、日付・金額・店名を読み取って経費の表にまとめる

  • 電話・問い合わせの一次対応営業時間外は出られない、折り返しに追われる

    AIが用件を聞き取り、内容を文字にして担当者へ届ける

  • 営業メール・返信文の作成毎回ほぼ同じ文面を、宛先ごとに書き直す

    相手に合わせた文面を下書きまで自動で用意。確認して送るだけ

  • SNS・ブログの投稿ネタ探し、文章づくり、投稿を毎日手作業で

    リサーチから文章・動画の作成、投稿までを毎日自動で回す

  • 予定の調整・日々の集計カレンダーや表を行き来して転記する

    カレンダー・表・チャットをつないで、転記そのものをなくす

ここにない作業も、まずはお聞かせください。「毎回同じ手順でやっていること」は自動化の候補です。

サービスServices

事務を、自動で回す。そのための、4つのお手伝い。

中心は、日々の事務作業の自動化です。お店や会社の顔になるホームページの制作も、あわせてお受けしています。

  • 01

    事務作業の自動化Back-office Automation

    領収書の読み取り、請求・見積の作成、集計や転記など。今の手順をうかがい、AIとプログラムで「人がやらなくていい形」に組み直します。

    Claude API ・ OpenAI API ・ Python ・ Google Workspace ・ n8n ・ Make ・ Zapier

  • 02

    AI応答・BotAI Assistant & Bot

    電話やチャットの一次対応、社内の「これどうするんだっけ」に答えるBotなど。SlackやLINEなど、普段お使いのツールの上で動かします。

    電話応答AI ・ Slack Bot ・ LINE Bot ・ Python

  • 03

    SNS・発信の自動化Social & Content Automation

    リサーチから文章・動画の生成、投稿までを無人で回す仕組みを構築します。

    Threads API ・ YouTube Shorts ・ note自動投稿 ・ 動画生成

    HTML / CSS / JS ・ Next.js ・ Three.js ・ GSAP
